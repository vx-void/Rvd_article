Проанализируй пользовательский ввод и определи тип гидравлических комплектующих.
Для каждого элемента ввода верни JSON объект с полями согласно типу:

- Для фитинга:
  ("type": "fitting", "chatInput": "оригинальный текст")

- Для адаптера:
   ("type": "adapter", "chatInput": "оригинальный текст")



ВАЖНО:
- Используй ТОЛЬКО указанные поля для каждого типа. Не добавляй лишние поля.
- Всегда возвращай массив объектов JSON.

примеры JSON
[
  {
	"type": "фитинг",
	"chatInput": "05 DKOL 12х1,5 (6) (0)(Г)"
  },
  {
    "type":"адаптер",
    "chatInput": "Адаптер BSP Г/Г 1\"-1\""
  }
]
